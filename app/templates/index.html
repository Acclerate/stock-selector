使用说明
  1. 从下拉框选择策略类型：短线中长线增强版增强版A，填写推荐数量（默认5只）。
  2. 点击 运行选股，系统自动扫描沪深300成分股（约250只主板蓝筹），根据历史K线计算技术指标并评分，完成后显示评分最高的 N 只。
  3. 点击 导出报告，生成 Markdown 格式的选股报告并下载，文件名包含时间戳。
  4. 点击 {{ llm_display_name }} 分析，将选股结果交给 {{ llm_display_name }} 生成深度研报，包含产业逻辑、三情景价格、买入/止损/止盈建议，支持流式实时输出。
  5. 表格中的买入价 / 止损价 / 止盈价均由 ATR 动态计算（止损 = 现价 - 2xATR，止盈 = 现价 + 3xATR），仅供参考，不构成投资建议。

数据说明

所有技术指标（RSI / MACD / KDJ / 布林带等）均基于历史收盘K线计算，并非实时 tick 数据。同一天内多次运行时，K线数据自动复用内存缓存，无需重复抓取。

建议使用时机

  • 收盘后（15:00 以后）当日K线已确认，结果最稳定
  • 次日开盘前复查，结合隔夜消息再决策
  • 避免在盘中使用，当日K线尚未收盘，指标不稳定

评级说明

  • A+（>=85分）：强烈关注
  • A（>=70分）：值得关注
  • B+（>=60分）：可操作
  • B（>=50分）：观望为主
  • C（<50分）：暂不参与
选股策略说明

短线 1-5 日动量策略（满分100）

  • RSI 20分：RSI < 30 超卖 +20；RSI < 40 偏低 +12
  • KDJ 20分：K/D 金叉且 J < 50 +20；超卖区 +15
  • MACD 15分：DIF/DEA 金叉 +15；红柱扩张 +10
  • 布林带 15分：价格触下轨 +15；中轨以下 +10
  • 量价共振 15分：放量上涨（量比>=1.5）+15
  • 资金流 15分：主力净流入 > 500万 +15

推荐阈值：总分 >= 60 且买入信号 >= 2

中长线 20-180 日趋势策略（满分100）

  • 趋势 30分：MA5/MA20/MA60 多头排列
  • 动量 15分：5日/20日收益率均为正
  • OBV+量比 15分：OBV 20日上升 + 量比 0.8-2.0
  • ADX 强度 10分：ADX > 25 且 +DI > -DI
  • 波动率 10分：年化波动 15-35%（适中）
  • 乖离率 10分：偏离 MA20 在 -10%~+15% 区间
  • 资金流 10分：主力净流入为正

推荐阈值：总分 >= 70

增强版 综合基本面+技术面（满分100）

  • 包含中长线全部技术指标
  • 基本面加成：ROE、利润增长率、股息率、PEG 估值
  • DMI 信号优化：方向性运动指标二次确认
  • 适合中期持仓，兼顾安全边际与成长性

推荐阈值：总分 >= 65

增强版A 11维全维度策略（满分100）

  • 技术趋势 20分：MA5/MA20/MA60 多头排列 + AdvancedIndicators 趋势评分
  • 基本面 20分：ROE(7) + 利润增长率(7) + 股息率(6)，连续化评分
  • 财务质量 15分：毛利率(5) + 净利率(5) + 负债率(5)
  • 估值分析 15分：PEG 估值(8) + PB 破净/低估(7)
  • 动量 10分：20 日收益率连续映射，正收益线性加分
  • 量能 10分：OBV 20 日变化率，资金持续流入加分
  • DMI 10分：DI 差值 × ADX 强度，趋势方向确认
  • 短线择时 15分：RSI(4) + KDJ(4) + MACD(4) + 布林(3)
  • 资金流精细化 10分：主力净流入(4) + 超大单占比(3) + 连续天数(3)
  • 龙虎榜 5分：近5日龙虎榜净买入额（5000万→满分）
  • 行业强弱 10分：个股20日涨幅 vs 所属行业20日涨幅

推荐阈值：总分 >= 75 | 原始满分150归一化至100
